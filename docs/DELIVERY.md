## گزارش تحویل «راستا»

پروژه Laravel 12 در `/workspace/rasta` ساخته و بررسی شد. مبنای بصری سه تصویر دریافت‌شده است؛ تصویر چهارم موبایل در پیام نبود. از بخش‌های قابل استفاده آرشیو منبع قبلی بازاستفاده شد و ورود، مدل اعضا، سیاست‌ها، داده‌ها و رابط مطابق درخواست بازسازی شدند.

### اجرا

دستورهای کامل در README آمده‌اند:

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
php artisan uja:setup
npm ci
npm run build
php artisan serve
```

رمز را فقط در ورودی مخفی `uja:setup` وارد کنید. هیچ رمز پیش‌فرض تعیین نشده است. در محیط ابری حاضر ابتدا `export PATH=/workspace/.runtime/bin:$PATH` و سپس `cd /workspace/rasta` اجرا شود؛ برای سرور از `php artisan serve --no-reload --host=127.0.0.1 --port=8001` استفاده کنید. سرور فعلی پاسخ ورود HTTP 200 و مسیر محافظت‌شده HTTP 302 داد. نشانی loopback فقط برای بررسی داخل محیط استفاده شده است و لینک عمومی نیست.

خطاهای یافت‌شده حین ساخت و آزمون پیش از ادامه برطرف شدند. آزمون مرورگر ویزارد **سه‌گامی** را با **پنج مرحله محصول** اجرا کرد. CSRF واقعی نیز با رد درخواست بدون توکن (HTTP 419) بررسی شد. هیچ خطای JavaScript در آزمون نهایی ثبت نشد.

### GitHub و بسته تحویل

Git در پروژه مقداردهی شد؛ شاخه `main` و کامیت‌های مرحله‌ای وجود دارند. اسکن فایل‌های قابل commit و قواعد ignore انجام شد. ZIP از فایل‌های ردیابی‌شده به‌علاوه خروجی build ساخته می‌شود؛ بدون vendor، node_modules، .env، دیتابیس یا محتوای خصوصی storage.

❌ مخزن خصوصی GitHub و push انجام نشده است. `gh repo create creativedesignuja-byte/rasta --private` امتحان شد؛ درخواست API با Forbidden شکست خورد. درخواست مستقل HTTPS نیز `CONNECT tunnel failed, response 403` برای api.github.com داد. خواندن مخزن قبلی با Git موفق بود؛ این دسترسی جایگزین مجوز ساخت مخزن نیست. بنابراین لینک مخزن ایجادشده‌ای برای ارائه وجود ندارد.

برای تکمیل انتشار باید دسترسی محیط به `api.github.com` و مجوز ایجاد مخزن خصوصی فراهم شود، یا مقصد مجاز ارائه شود. هیچ token یا رمز محرمانه‌ای در چت درخواست نشده است. بعد از رفع دسترسی، ساخت مخزن خصوصی و push شاخه main باقی می‌ماند.

### فرض‌ها

- سه تصویر دسکتاپ در پیام موجود است؛ تصویر چهارم موبایل موجود نیست. موبایل مطابق قواعد متن با عرض ۳۹۰ پیکسل پیاده‌سازی می‌شود.
- SQLite برای توسعه و تست؛ سازگاری ساختار با MySQL حفظ می‌شود.
- پروژه جدید در /workspace/rasta ساخته می‌شود؛ پیش‌نمایش gh-pages قبلی مرجع تصویری کمکی است.
- درخواست مستقیم کاربر برای ایجاد مخزن خصوصی GitHub بر محدودیت GitHub در سند پیوست مقدم است؛ هیچ pipeline ساخته نمی‌شود.
- همه اعضا پس از ورود مشترک می‌توانند پروژه و تسک را ویرایش کنند؛ نظر و پیوست فقط توسط نویسنده ویرایش/حذف می‌شود.
- رمز فقط از ورودی مخفی دستور uja:setup دریافت می‌شود؛ هیچ رمز پیش‌فرض یا نمونه‌ای ثبت نمی‌شود.
- بخش‌هایی از اسکلت Laravel، اجزای Blade و CSS از آرشیو منبع داخل مخزن قبلی بازاستفاده و برای این مشخصات اصلاح شدند؛ اعتبارسنجی قدیمی مبنای ادعای تکمیل نیست.
- نسخه‌های composer.lock موجود به PHP 8.4 نیاز دارند؛ این نسخه نصب و استفاده شد و شرط PHP 8.2+ سند را پوشش می‌دهد.
- داده‌های موقت تست فقط در SQLite ایزوله ایجاد و حذف می‌شوند؛ هیچ داده نمونه در نصب نهایی، Seeder یا ZIP وجود ندارد.
- آمار «تسک‌های امروز من» فقط مهلت امروز و «مهلت‌های نزدیک» بازه امروز تا هفت روز بعد را شامل می‌شود؛ کارهای عقب‌افتاده در قدم‌های بعدی با رنگ هشدار دیده می‌شوند.
- فرمت پیوست‌ها به PDF، PNG، JPEG، WebP و TXT محدود است؛ فایل در مسیر خصوصی نگهداری می‌شود.
- چون URL دیگری داده نشده، مقصد درخواست‌شده GitHub برابر creativedesignuja-byte/rasta در نظر گرفته شده است؛ ساخت آن به دسترسی API نیاز دارد.

### محدودیت‌های باقی‌مانده

- مرجع چهارم موبایل دریافت نشده و تطبیق دقیق آن قابل تأیید نیست.
- انتشار GitHub به دلیل محدودیت شبکه انجام نشده است.
- MySQL 8 از طریق تنظیم Laravel پشتیبانی می‌شود؛ تست مستقل MySQL در این محیط اجرا نشده است. تمام تست‌های دیتابیس روی SQLite بوده‌اند.
- در نصب تحویلی عمداً رمز مشترک تنظیم نشده؛ مالک باید `uja:setup` را با رمز انتخابی خود اجرا کند.
- انتشار روی سرور عمومی و pipeline در محدوده این کار نبود و انجام نشده است.
